# 小学数学 · 统计表转统计图

四到六年级的四个单元：一份统计表画成什么图，由这道题要回答什么决定——比多少用条形，看变化用折线，看占比用扇形。表给出准确的数字，图给出谁多谁少、在升还是在降、各占几成。

## 用到的图表

- [柱状图](/chart/bar) —— 四年级上·单式条形：一个项目一根柱，比多少
- [柱状图](/chart/bar)（多系列）—— 四年级下·复式条形：一个项目两根柱，两个班对着看
- [折线图](/chart/line) —— 五年级下·折线：描点连线，看升还是降
- [饼图](/chart/pie) —— 六年级上·扇形：扇区大小就是占比
- [条形图](/chart/horizontal-bar) —— 课堂追问里同一张表的另一种排法

## 实现要点

- 四张表到四张图的对应，是教材按「问题」排好的顺序：一个项目一根柱（比多少）、两根柱（做对比）、描点连线（看变化）、扇区（看占比）——先问这道题要回答什么，再挑图；
- 条形图的纵轴从 0 开始，是库对非负数据的默认行为：纵轴一截断，柱子的高矮就成了假象，这是读图练习里第一个要纠正的错误；
- 折线图反过来把纵轴抬到 80 分起（`yAxis.min`）：同一批分数，从 0 分起是一条几乎平直的线，从 80 分起才看得出哪一次进步最大——纵轴起点，决定了这张图能不能回答这道题；
- 折线图的「先描点，再连线」对应 `showSymbol: true` 与不加 `smooth`，画出来正是两点之间的直线段；注解只留两处（`region` 圈出进步最陡的一段、`callout` 标出六次一共提高 12 分），单图三处的注解预算全花在教学信息上；
- 扇形图开 `piePercentMode`，百分比直接标在扇区上，学生不用心算；
- 课堂追问那块的数据就是第一张表：同一份数据换成条形 / 横向条形 / 扇形，回答的是「谁最多 / 排座次 / 各占几成」三个不同的问题；老师要把自己班的统计表搬上来，把数据贴进 [AI 生成](/guide/ai) 一句话就能出图，正好当板书。
