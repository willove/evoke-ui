# 热力图 heatmap

在二维网格上按数值着色：哪里密度高、什么时段有规律，颜色深浅一眼呈现。"星期 × 时段"活跃度是最经典的用法。

## 何时使用

- 两个维度交叉的**密度/强度**表达（时段 × 品类、地区 × 指标）；
- 数据量大到散点互相重叠、看不出形态时，热力是散点的密度化替代；
- 周期性规律（按天/小时）的展示效果极佳。

## 示例

专属数据字段 `heatmapData`（`{ x, y, value }`），色阶取默认蓝阶，数值越大颜色越深。

## 配置要点

- 只传出现的组合即可，网格自动补齐坐标轴类目；
- 悬浮读取格子坐标与数值；
- 想看点与点的相关关系而非密度时改用[散点图](/chart/scatter)。
