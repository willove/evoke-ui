# 瀑布图 waterfall

表达"从起点到终点经历了哪些增减"：柱子接力悬浮，直观展示各环节的贡献与拖累。经营分析里的预算增减、损益构成、库存变化都用它。

## 何时使用

- 有一个明确的起始值与结束值，中间是**正负增减项**；
- 想突出每一项对结果的影响方向与大小。

## 示例

沿用 `labels` + `series` 数据模型（`type: 'waterfall'`），数据按流程顺序给出，正负值自动决定增减着色与悬浮位置。

<DemoBlock>
  <ev-chart
    :options="{
      type: 'waterfall',
      title: '年度预算增减',
      labels: ['年初预算', '人力追加', '市场削减', '采购优化', '年末预算'],
      series: [{ name: '预算变动', data: [1000, 260, -180, -120, 960] }],
    }"
    :height="260"
  />
</DemoBlock>

### 利润桥

财务复盘的标准图：营业收入一路扣到净利润，每一项费用「吃掉」多少一目了然——哪根柱子最长，成本就谈哪里。

<DemoBlock>
  <ev-chart
    :options="{
      type: 'waterfall',
      title: 'Q2 利润桥（万元）',
      labels: ['营业收入', '原材料', '人力成本', '物流仓储', '营销费用', '净利润'],
      series: [{ name: '损益', data: [1860, -520, -430, -210, -260, 440] }],
    }"
    :height="280"
  />
</DemoBlock>

### 工资条拆解

生活场景一样好用：应发工资怎么一步步变成实发——五险一金、专项扣除、个税各扣多少，比文字工资条直观得多。

<DemoBlock>
  <ev-chart
    :options="{
      type: 'waterfall',
      title: '月薪拆解（元）',
      labels: ['应发工资', '五险一金', '专项附加', '个人所得税', '实发工资'],
      series: [{ name: '工资单', data: [25000, -4200, -1500, -980, 18320] }],
    }"
    :height="280"
  />
</DemoBlock>

## 配置要点

- `labels` 表达流程节点语义（"年初/追加/削减/年末"），不要用纯数字序列；
- 负值项自动向下悬浮，正向正向接力；
- 需要看各项占比构成时改用[饼图](/chart/pie)或[堆叠柱状图](/chart/stacked-bar)。
