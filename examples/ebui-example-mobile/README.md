# 移动端 H5 工作台示例

演示用 ebui 组件搭建**移动端页面**的简单模式样板：单包打包（与桌面端共用同一个 ebui 包和构建链，无独立移动端分支、零额外运行时依赖），移动适配完全由页面级响应式样式完成。

## 运行

```bash
# 在 monorepo 根目录
pnpm --filter @wil-works/ebui-example-mobile dev
# http://localhost:8628（手机模式请用浏览器设备模拟或局域网手机访问，已开启 --host）
```

## 移动端策略

| 决策 | 说明 |
| --- | --- |
| 单包兼容 | 与桌面示例共用 `@wil-works/evoke-business-ui` 源码级依赖，构建产物与桌面完全一致（简单模式：不拆移动端构建） |
| 组件选型 | 只用天然自适应的组件（额度墙 / 进度 / 状态标签 / 分段器 / 步骤条），规避 DataTable 等宽表格组件 |
| 布局壳 | 420px 居中手机列 + `100dvh` 弹性列布局 + 底部 sticky 标签栏（`safe-area-inset-bottom` 适配） |
| 触控友好 | 可点击元素高度 ≥ 32px，主操作按钮独立成行 |

## 页面结构（四个底部页签均为真实可交互页面）

- **首页**：快捷数据 2×2、简单模式开关、本月用量（CreditsProgress）、报销审批进度（Steps）、快速登记（自适应表单）、待办/订单列表
- **订单**：关键词搜索 + 状态筛选 + 订单卡片（金额 / 状态 / 物流进度 / 查看详情）
- **消息**：类型筛选、未读红点、点按已读、一键全部已读
- **我的**：个人资料卡、本月概要（Progress）、功能菜单（我的报销单/消息设置/账号安全）、退出登录

底部标签栏：sticky 置底 + 安全区适配，消息页签带未读数角标。

## 结构

```
src/
  App.vue             # 直接挂载移动页面
  pages/
    MobileHome.vue    # 移动工作台页面（自包含，可被文档站源码级引入预览）
    mock.js           # 数据
```

## 与文档站的关系

`pages/MobileHome.vue` 被 `evoke-business-ui-docs/examples/mobile.md` 与全屏子站点 `/examples/live/mobile` 直接 import 作为在线预览（桌面浏览器中以 420px 手机列宽呈现）。
