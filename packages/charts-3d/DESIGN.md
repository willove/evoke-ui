# Charts 3D 视觉设计标准（v1）

本文件是三维图表视觉标准的唯一事实源：改视觉先改标准再改码。
`--ev-*` 令牌语义、色系 id、tooltip 结构、无障碍底线与 evoke-charts 的 DESIGN.md 同规，
本文只写三维独有的裁定。

## 1. 设计原则

1. **形体感来自光照，不来自描边**。立体感由面法线 × 主光的明度着色给出；默认不给数据面加描边（悬浮强调除外）。
2. **坐标框衬托数据，不遮挡数据**。墙与轴的取边跟随相机：背墙永远在远侧，轴线刻度贴近边。
3. **标签可读性优先于完整性**。屏幕空间防碰撞，撞了就丢标签，绝不叠字；网格线不随标签抽稀。
4. **换视角不换观感**。光照默认跟随相机（肩后主光），任意 yaw/pitch 下形体都处于受光面。

## 2. 色彩

### 2.1 系列色

- 令牌槽位、缺省色板、内置色系（`classic/aurora/sunset/morandi/forest/ink/candy`）与 evoke-charts 逐位一致；同 id 色系两库同色。
- 暗色板 = 同色相提亮，随 `html.dark` 换挡。

### 2.2 结构色（非数据元素）

| 元素 | 亮色 | 暗色 |
| --- | --- | --- |
| 网格线 | `rgba(31,41,55,0.10)` | `rgba(229,231,235,0.12)` |
| 墙面填充 | `rgba(31,41,55,0.035)` | `rgba(229,231,235,0.05)` |
| 盒体棱线 | `rgba(31,41,55,0.16)` | `rgba(229,231,235,0.20)` |
| 轴刻度文字 | text-color-secondary | 同（暗色值） |

### 2.3 连续色带（曲面 / 色标散点）

- 每套色系配低→高色带，明暗各一套（暗色反转为「低暗高亮」），取样为纯色离散阶梯（兼容 SVG 导出）。
- 内置色带：`classic / aurora / sunset / viridis / heat / mono`；曲面默认随 `palette`，可 `surface.ramp` 覆写。

## 3. 光照与材质

- 默认**相机相对主光**：方向 ≈ 左上前方（`offset [-0.45, 0.6, 0.66]`），`ambient 0.56`、`intensity 0.88`。
- 着色 = HSL 明度缩放（保色相饱和度），结果明度钳制 `[0.06, 0.94]`；禁「向白色混合」（会掉饱和度）。
- 顶面最亮、正面居中、侧面最暗的次序是默认验收线；同视角顶面相对亮度必须高于侧面。
- 双面可见面片（曲面、面带）背向时法线翻转再着色，禁止出现「反向光照发黑」。
- `lighting.direction` 显式给方向时固定于世界系（旋转可见明暗变化），仅建议用于展示场景。

## 4. 相机与构图

- 世界 Z 轴向上；笛卡尔图共用 1×1×0.62 的世界标架（数据域归一化），相机手感跨图型一致。
- 默认机位 yaw -52° / pitch 27° / fov 42°；目标点柱类 `[0,0,0.31]`、饼类盘心。
- `autoFit` 只反解 distance（包围球 + 1.05 安全系数），不动方位；用户一旦手动交互即停用。
- pitch 钳制 `[2°, 88°]`、distance 钳制由 min/max 界定；越界配置回落默认，不允许 NaN 进管线。

## 5. 坐标框与标签

- 取边：X/Y 轴线贴**近边**，Z 轴立**远角**，墙贴远侧；`box.walls: 'back' | 'side' | 'all' | 'none'`。
- 地面网格 = X 刻度纵线 + Y 刻度横线；墙内网格含 Z 横线与墙面竖线；网格密度上限 30 条/轴。
- 刻度标签先投影到屏幕再做**贪心防碰撞**（矩形 + 2px 间距），被丢弃的不画；轴名沿外推方向以 38/54/70px 逐级退避，全撞则放弃。
- 标签外推方向 = 「远离盒体」的世界方向投影到屏幕，任意视角下标签都在盒外侧。

## 6. 图型细则

### 6.1 bar3d
- 柱体为封闭长方体，顶点缠绕法线朝外，开启背面剔除；宽/深默认占带位 62%。
- 缺失值不占位；零值柱保留（0.0004 世界高度封顶面，防「看穿地面」）。
- 柱底投 10% 黑贴地阴影（`bar.shadow: false` 关）。

### 6.2 line3d
- 线宽默认 2.4、圆角连接；数据点默认开（半径 3.6、白描边）。
- **落地投影是必需读数辅助**（非装饰）：竖直虚线（22% 透明度）+ 地面折线；`line.dropLines: false` 关。
- 面带（`line.area`）为折线垂直落地 curtain，20% 透明度，双面可见。

### 6.3 scatter3d
- 半径默认 5，默认按视深缩放（`scatter.depthScale: false` 关）；落地虚线 22% 透明度。
- 色标模式（`scatter.colorScale`）把 Z 映射到色带，图例区换成连续色标。

### 6.4 surface3d
- 面片上限 48×48，超出按等距抽稀（首末必含）；线框逐格短段抽样（上限 32×32）——**禁止整条横/纵线**（单一质心深度会整线穿帮）。
- 面色 = 四角均值在色带上取样；双面可见；`surface.opacity` 默认 1。

### 6.5 pie3d
- 盘平放于地面（XY 面），半径默认 0.42、厚度默认 0.18；弧采样密度 72 段/整圆。
- 扇区五类面（顶环/底环/外弧/内弧/两径向端面）缠绕全部法线朝外，整块开启背面剔除。
- 扇区间默认 0.57° 隙角；悬浮扇区**整体上浮 0.055 世界单位**（位移强调，不用变色）；盘底投黑色软阴影环。
- `pie.innerRadius > 0` 即环形。

## 7. 图例与色标

- 图例为二维覆盖层，顶部居中为默认（`top / bottom` × `start / center / end`）；隐藏项保留并 35% 透明度显示（可点回）。
- 连续色标画在右侧 padding 带（预留 48px）：10px 色条 + min/max/轴名，纵向居中于绘图区。

## 8. Tooltip

- 结构与 evoke-charts 同构：标题 + 圆点/名称/数值行；默认模板一律 HTML 转义，`formatter` 返回值由使用方自负。
- 散点三元组展示 X/Y/Z 三行；曲面展示 X/Y/值；饼展示值 + 占比。

## 9. 动效

- 进场默认 600ms easeOut：柱/线/散点/曲面按 progress 长高，饼为「角度扫入 + 厚度生长」双节奏（0.85/0.8 错峰）。
- 相机交互不做补间（跟手优先）；`animation.enabled: false` 直接终态。

## 10. 交互规范

- 拖拽 = 环绕（抓物语义：向下拖看到更多顶面），灵敏度 170/span °/px 归一；Shift 拖 = 平移；滚轮 = 指数缩放；双击 = 复位。
- 双指捏合 = 缩放；拖拽中抑制 camera-change、结束时补发一次终态。
- 键盘：方向键环绕（8°/步）、`+/-` 缩放、Home 复位、Enter 触发 click、Escape 清除悬浮。
- 拾取复用渲染投影：面用多边形包含、线用段距离、点用半径容差；多命中取**视深最近**者。

## 11. 无障碍

- 容器 `role="img"` + `aria-label`（默认 `3d-{type}-{title}`），可聚焦；悬浮信息写入 `aria-live=polite` 区域。
- 空/错态有文字占位，错误边界兜底渲染异常，不允许白屏。

## 12. 大数据量

- 曲面按面片上限抽稀；散点/折线落地线随数据量线性增长，万级点云建议关闭 `dropLines`。
- 深度排序为 O(n log n)，图元总量建议 ≤ 1 万；超出优先降采样而不是调相机。
