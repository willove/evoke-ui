# Evoke Charts 视觉设计标准（v1）

本文件是图表渲染层视觉的**唯一事实标准**：调整任何视觉默认值，先在此文件定稿，再改代码。
对标对象：阿里云/腾讯云控制台监控图、AntV、ECharts 官方示例的克制风格。
状态标记：✅ 已实现 · 🔜 待实现（按优先级排序，落实一项勾一项）。

---

## 1. 设计原则

1. **数据墨水比优先**：网格、轴、边框等结构元素退到视觉背景，墨水留给数据。
2. **克制**：一个图表只允许一个视觉焦点（曲线/柱体本身）；默认无圆点、无阴影、无描边装饰。
3. **一致性**：同层级元素（所有轴标签、所有图例项）字号字色完全一致；色彩饱和度/明度成套。
4. **可读性优先于装饰**：任何装饰性效果不得降低曲线/柱体与背景的对比度。

## 2. 色彩

### 2.1 系列色（数据色）✅

- **数据色板与状态语义色解耦**：优先读取专用令牌 `--ev-color-series-1..8`，
  槽 1 缺省回读 `--ev-color-primary`（品牌主色跟随/换肤不断）；
  未定义的槽位逐槽回落内置成套色板（取材 AntV 经典系，品牌蓝锚定）。
- 顺序即取色顺序：第 1 系列 蓝（主色），后续按槽位顺序。
- **语义色边界**：success / warning / danger / info 是状态语义色，不再默认进入
  数据色板；仅在数据本身承载该状态语义时由使用方通过 `series[].color` 显式指定。

#### 内置色系（palette 一键应用）

在令牌跟随之上提供成套内置色系：`options.palette` 填色系 id 即整图固定该色系。
**固定语义**：应用后系列色不再读取 `--ev-color-*` 令牌——宿主换主色、换肤、
改扩展槽位都不影响本图配色；明暗两套色值随暗色模式由色系自带换挡（内建，
非宿主变量）。结构色（网格 / 轴文字 / 标题）仍随宿主明暗，保证可读性。

- 取色优先级：`theme.colors`（手工数组，最高）> `palette`（内置色系，固定）>
  令牌跟随（默认，槽位缺省回落成套色板）；
- 每套色系满足同款验收：取色顺序相邻色相差 ≥ 30°（饱和度 S < 20% 的灰调槽
  豁免）；暗色板同色相提亮（S ≥ 20% 槽位）；
- 语义色边界不变：色系只定数据系列色，状态语义仍由使用方显式指定。

| id | 名称 | 适配场景 |
| --- | --- | --- |
| classic | 经典 | 当前缺省色板的固化版，品牌蓝锚定；想保住默认观感不随换肤时用 |
| aurora | 极光 | 科技 SaaS / 数据产品——冷调现代，蓝绿紫主打的仪表盘观感 |
| sunset | 落日 | 消费零售 / 生活方式 / 营销复盘——暖橙珊瑚主导，热情有温度 |
| morandi | 莫兰迪 | 人文 / 咨询报告 / 印刷排版——低饱和灰调，长文配图不抢字 |
| forest | 林间 | 健康 / 环保 / 农业供应链——自然绿主导，ESG 与可持续叙事 |
| ink | 墨蓝 | 金融 / 政企 / 严肃年报——克制深稳，深蓝为骨、暖色点缀 |
| candy | 糖果 | 营销活动 / 年轻品牌 / 大屏展示——高饱和明快，视觉抓人 |

色值唯一事实源在 `src/palettes.js`（每系浅 / 暗各 8 槽，与 2.1 表同构），
新增或调整色系先改实现表再回填本节 id 与场景边界。

### 2.3 面积填充

- `type: 'area'` 或系列 `area: true`：线性渐变 `颜色 @25% → @2%`（顶→底）。
- 堆叠面积：顶层 `@33%`，避免多系列叠色过深。
- 系列可用 `areaOpacity` 覆写整体透明度。

## 3. 线条与数据点

### 3.1 雷达图

- **填充与面积图同标准**：线性渐变 `颜色 @25% → @3%`（顶→底），多系列叠加不糊；
  `area: false` 关填充只留线框；悬停系列填充微增（@35%→@5%）；
- **线宽 1.5px**（与折线一致），悬停系列 2.5px；
- **顶点符号默认不画**（与折线图同一规矩）：`showSymbol: true` 才画 r3 实心点，
  悬停顶点画「底色圆 + 外环」；
- 网格：5 档多边形环 + 轴线，1px 发丝线；所有维度同 `max` 时在最上轴旁标注
  环刻度数值（10px 次要色），维度各自定 max 时不标（环刻度会有歧义）；
- 维度标签：12px 次要色，`radarLabelOffset` 控制与外环间距（默认 12）；
- **环底色**（`radarRingFill: true`）：**同心圆环带**交替浓淡（由外向内叠画，
  奇偶环取网格线色 50%/22% 两档，参考 AntV 雷达示例），维度文本沿外圆分散
  四周与环带同圆心——增强「由内到外递进」读感；默认关闭（零墨水背景）；
- **轴线悬浮高亮**：悬浮维度标签或轴顶点附近时，该轴线升至主文字色 1.5px、
  对应维度标签升主文字色加粗、各系列该顶点画实心点——「这个维度上谁强」
  一眼可读；进出随 220ms 缓动（与悬浮动画同一通道）；
- **图例悬浮强调**：走全局 focusSeries 通道（其余系列降至 22%），焦点系列
  线宽同步升至 2.5px。

### 3.2 旭日图

- **单环同厚**：环带由内到外按层级均分半径预算，中心留白取半径 22%，各层厚度
  一致；层与层、段与段之间用背景色 2px 描边分隔。不做按数值外延的花瓣/齿状
  变形——那会带来断裂感、双描边光晕，外圈边缘也不再是一条干净的圆；
- **分支同色系**：一级分支各取一个色相（系列色板顺序），**子孙继承该色相**，
  只按深度向背景方向混合：浅色主题向白 26%/层（上限 60%），深色主题向黑
  14%/层（上限 34%）——一条射线读下来是同一色族的深浅，外圈大面积不刺眼；
- **子扇区收敛父扇区**：子节点扫角 = 父扇区扫角 × 本节点在兄弟中的占比，
  兄弟首尾相接铺满父扇区——同一射线穿过的各层是同一条路径；子层自己铺满整圆
  会让外圈压到别的分支上，这是旭日图最容易错、也最毁观感的一条；
- **半径预算与饼图同口径**：`min(宽,高)/2 - 20` 与 `宽/2 - (引线 + 外置文本宽)`
  取小——外置标签必须落在预算内，不压圆盘、不出画布；
- **标签一律沿半径旋转**（对齐 ECharts 形态）：各环标签都从圆心向外走、居中在自己
  的环带里，左半圆翻转 180° 保证从左往右读；不再把外圈标签牵到盘外用引线——
  引线标签是饼图/环形图的形态，旭日图靠旋转标签把信息留在盘内；
- 字号 11px（内环加粗），文字色**正文色优先**（浅色主题近黑、暗色主题近白），
  仅当扇区底色深到正文色不可读（isLightColor 判暗）才按对比度反白——逐层提亮
  后的中间调一律深字，不再出现看不清的白字（用户定则：能用黑色就用黑色）；
  `showValues` 且环厚 ≥ 26px 时，数值作为第二行沿环厚方向堆叠；
- 放不下的才不画：环厚 ≥ 12 且弦长 ≥ 11 且文字长度 ≤ 环厚 + 20px（环带窄时
  允许轻微越界），更长的名字交给 tooltip；
- **悬浮聚焦子树**：悬浮某节点时，它与其全部子孙保持原色、其余段与标签淡出到
  0.25（220ms 缓动），被悬浮节点自身再加深一档（同色，不引强调色）——层级类
  图表统一用这套「聚焦路径、淡出其余」，不做位移、不做阴影、不加描边。

### 3.3 漏斗图

- **一色到底（不用彩虹）**：漏斗是同一个流程的逐层收窄，不是五个并列类目——段色取
  一个基准色相（`funnelData[].color` 显式指定优先，否则主题首色），按**层序**向背景
  方向混合：浅色主题向白 15%/层（上限 60%），暗色主题向黑 12%/层（上限 45%）。
  与旭日图「分支同色系」同一机制（旭日按深度、漏斗按层序）：多色相平铺会把「一层
  层收窄」读成并列类目，末层落到暖色还会被误读成告警——流程/层级类图统一走同色族深浅；
- **宽度即数值，末端不收针尖**：每层上宽 = 本层值 / 最大值 × 80% 绘图区宽，下宽 =
  下一层的值；**末层下宽等于自身宽度**（不再额外收 50% 成尖），漏斗底部收成一条平边
  而不是针尖；层间用 2px 背景色描边分隔，不画阴影、不加描边装饰；
- **数值极差悬殊不回避**：极差 20 倍以上时尾层必然很窄，这是数据的真实形态（转化
  漏斗就该看出「漏得多」），不做对数/开方变形；要让尾层更可读，用
  `funnelMinRatio`（尾层最小宽度占最大值比例，0–0.5，默认 0 = 严格等比）把宽度
  映射改成 `min + (1−min) × 值/最大值`——压缩的是尾段，单调性不变；
- 段内两行标签：名称 13/600 + 数值 11/400，行距 18px（中心 ±9），文字色按段底色取
  对比度更高的一方（逐层提亮后中间调仍是深字，不写死反白）；
  梯形中位宽放不下（两侧各留 14px）或层高 < 36px 时自动转外侧引线标签；
- 外侧标签右对齐两行：名称 12/600 主色 + 数值 11 次要色，纵向最小步进 36px
  防重叠，虚线引线随标签位移斜连；百分比取一位小数但不补零（100% / 33.3%）；
- 标签随进度平滑淡入（进度 72% → 100% 区间 0 → 1），形状展开用 cubic
  ease-out 收尾，不硬蹦；
- 悬浮层片加深一档（同色向黑 8%），不位移、不加阴影；
- `pyramid: true` 反转绘制顺序（金字塔形态），配色仍按数据层序取值。

### 3.4 矩形树图

- 与旭日图共用同一套层级强调：悬浮某矩形时它与其子孙保持原色、其余淡出 0.25
  （220ms 缓动），被悬浮矩形加深一档——不画阴影、不加描边（阴影是库里唯一的
  例外，已按「默认无阴影」原则撤掉）；
- 格内标签：父节点左上角 11px 加粗；叶子居中 15px（顶层）/ 11px，格高 ≥ 36px
  时补一行「数值 (占比)」；文字色按格底色取对比度更高的一方；宽 < 50px 或
  高 < 24px 的格子不标字，交给 tooltip；
- 单元格圆角 3px，层级之间用背景色 2px 留白。

| 项 | 标准值 | 覆写 |
| --- | --- | --- |
| 默认线宽 | 1.5 | `series.lineWidth` |
| 监控带 / 迷你图 | 1.25 | 同 |
| 强调线（单系列主图） | 2 | 同 |
| 线帽/拐角 | round | — |
| 数据点圆点 | **默认不绘制** | `series.showSymbol: true` |
| 悬浮点 | 空心圆环 r4.5 / 环宽 2（showSymbol 关闭时同样生效） | — |
| 平滑曲线 | 默认直线段；`series.smooth: true` 单调三次插值（过点无过冲），chart 级 `options.smooth` 可整图开启 | `series.smooth` |

### 3.5 桑基图

- **节点列布局**：节点按拓扑深度（源 → 汇）从左到右分列，列内垂直均分；
  节点高度 = max(入流, 出流) / 全图最大值 × 绘图区高 × 0.8，节点宽 14px 圆角 3；
- **同色系按源继承**：每条流带颜色取**源节点**的槽位色，不按目标换色——
  流向是「从哪来」的叙事，同一源出的流保持同色，读线不追色；
- **流带**：三次贝塞尔水平带（cubic 控制点取横向中点），宽度 = 流量占比；
  默认透明度 0.35（暗色 0.3），悬浮流带升至 0.65、同源同宿流带随之强调，
  其余流带降至 0.12——焦点单一通道，不做位移；
- 节点标签 12px：入度侧靠左、出度侧靠右、中间列居中于节点上方，
  放不下自动截断省略；悬浮节点：相连流带强调 + tooltip 显示节点总流量；
- `sankey.nodeAlign: 'justify' | 'left'` 控制末端节点是否右缘对齐（默认 justify）。

### 3.6 韦恩图

- **圆心与半径**：每集合半径按 √value 等面积映射（面积即数值）；半径预算按
  集合数分档——1–2 集合取绘图区高 46%（宽 24% 溢出保护），3 集合取高 30%
  （宽 20%），主体尽量占满（用户定则：主体不能小）；圆距按交集面积近似反解
  （Euler 近似，允许误差），整体质心居中于绘图区；
- **填充形态**：基础韦恩图各圆填充系列色 @45%，圆与圆交叠自然加深（不额外
  画交集色块，避免三集合时假色）；空心韦恩图（`vennHollow: true`）只描边
  2px 系列色、不填充，重叠关系靠描边交叉读；
- 集合标签 12px/600 置圆心上方 r×0.4 处，交集值（有显式交集数据时）标在
  透镜区域中心 11px 次要色；
- **悬浮**：命中圆整圆强调（填充 +15% 不位移）、其余圆降 55%；
  悬浮交集区两圆同时强调；tooltip 显示集合名 + 数值。

### 3.7 弦图与弧长连接图

- **环形弦图**（`type: 'chord'`）：节点弧段均匀分布在圆周（弧长按节点值占比时
  `chordByValue: true`），节点弧 14° 圆角、半径 = min(宽,高)/2 − 30（外侧仅留
  标签带，主体尽量大）；连接带为三次贝塞尔闭带（控制点取圆心），宽度 = 关系值 /
  最大值 × 最大带宽，颜色取**源节点**槽位色 @30%（同桑基「按源继承」），悬浮升至
  0.7、其余降至 0.1。弦图只有色带形态——圆点弧线的环形形态归弧长连接图（下）；
- **线性弧长图**（`type: 'arc'`）：节点沿水平轴均布为圆点（r6），连接为上半
  椭圆弧（ry = 水平距 × 0.42），弧色同源节点 @35%、粗 1.5–6px 按关系值线性映射；
  **构图贴底**：节点行 + 标签带（30px）贴绘图区底缘，中部全高让给弧区，
  **弧顶距绘图区顶 ≥ 24px**（不压标题）；标签在轴下方 14px，竖直短刻度对位；
- **环形弧长连接图**（`type: 'arc'` + `arcCircular: true`，弧长图的环形形态）：
  节点为圆点（r6，悬浮 r7.5）均匀排圆周，关系为过圆心的三次弧线（描边非色带），
  **连线两端锚在节点圆点上**（midAngle，不留缺口），线宽 1.5–6px 按关系值线性
  映射，颜色同取源节点色——适合节点多、关系稀疏的闭合网络（不强调节点流量占比）；
- 三形态共用「源色继承 + 悬浮聚焦」纪律：悬浮某条连接，强调自身、淡化其余；
  悬浮节点，强调与该节点相连的全部连接 + tooltip 汇总出入度；进出均随
  220ms 缓动（见 §13.2）。

### 3.8 甘特图

- **行带**：每任务一行，行高 = 绘图区高 / 任务数（上限 44px），条高 = 行高 × 0.52
  圆角 4；左侧任务名列固定宽（最宽任务名实测 + 16，夹 80–180），15% 灰底隔行
  （斑马纹取 `--ev-fill-color-light` 档）；
- **进度语义**：完成段用任务色实心、剩余段同色 @25%，完成段右缘不加分隔线
  （色差自明）；`progress` 缺省按无进度渲染；里程碑（`milestone: true`）画
  菱形 10px 于日期点；今日线：primary @50% 竖虚线 + 顶部「今日」11px 标注；
- **依赖箭头**（`dependsOn: [name]`）：完成段右缘中点 → 依赖任务条左缘中点，
  正交折线 1px 次要色 + 实心小三角，悬浮任务时其依赖链升至主文字色；
- 时间轴：底部时间刻度自动抽稀（同 §4 拥挤策略），悬浮行整行高亮 @6% + tooltip
  （任务名 / 起止 / 进度）；行高不足 22px 时行内进度标签改 tooltip。

### 3.9 散点图增强形态

- **点标注**：`pointLabels: true` 时每点旁画 `label` 文本（11px 次要色，
  右上 45° 偏移 8px），重叠检测复用 `layoutLabelsAvoidOverlap`，放不下的不画；
- **四象限**：`quadrant: { xMid, yMid, labels? }` 以均值或显式中线画十字参考线
  （1px 虚线次要色），四角标签 11px 次要色斜体；象限底色不做（保持零墨水背景）；
- **颜色通道分组**：点带 `group` 字段时按组聚合取系列色（同组同色）、
  图例按组聚合（一组一项），回归线可按组各画一条（`trendlinePerGroup`）；
- **抖动**：`jitter: number`（px，0–20）给重叠点确定性偏移（基于索引伪随机，
  同数据同偏移，重渲染不跳），只动绘制坐标不动 tooltip 坐标；
- **回归线**：`scatterTrendline: 'linear'` 时线旁标 `R²=0.xx`（10px 次要色，
  虚线样式不变）；
- **分面**（`facet: true` + `group`）：按组切分绘图区为小倍数网格（每格独立
  x/y 范围），格标题 11px 加粗，共享轴不重复画刻度；命中测试按格归组；
- **散点矩阵**（`type: 'scatter-matrix'`）：`matrixFields` × `matrixData`
  生成 n×n 小倍数——对角格写字段名（11px/600 居中），非对角格画散点
  （行列字段互为 x/y），格间距 8px；单格悬浮高亮该格边框 + tooltip。

### 3.10 K 线 + 成交量

- `volumeData`（与 candleData 等长的数值数组）开启副图：绘图区下部 24% 为
  成交量带，K 线压缩到上部 76%，两带间以网格线分界；量柱颜色跟随当日涨跌色
  @55%，宽度与 K 线实体同宽；
- 成交量带不画轴（量纲从属，不与价格轴竞争读数），最高量柱顶部可标 max 值
  10px 次要色；
- **图例联动**：开启副图后图例出现「成交量」项，点选显隐整条量带（K 线自动
  回铺全高）——图例交互走既有 hiddenSeries 通道。

### 3.11 仪表盘指针与外观定制

- **弧向语义**：`startAngle` / `endAngle` 为数学角约定（0° 在右、逆时针为正，
  同 ECharts），默认 220 → -40 呈经典形态——**进度弧走上方、开口朝下**；
  半盘仪表传 `startAngle: 180, endAngle: 0`（禁传弧度）；
- **指针**（`gauge.pointer: { show: true }`）：从圆心到当前值角的箭针——
  针身三角形（根部宽 8px、长 = 环内缘 − 14px），针尾小圆帽 r5（底色填充 +
  针色描边 2px）；针色默认取进度色，`pointer.color` 可覆写；
  指针随进度动画同步扫动；开启指针时中心数值下移避让（盘心下方空档，
  随半径走 max(26, R×0.45)）；
- **外观定制面**：`gauge.axisWidth`（环厚，默认 20）、`gauge.tickCount`
  （刻度数，默认 5）、`gauge.valueFontSize`、`gauge.showTicks: false`、
  `gauge.tickMarks`（短刻度线，指针模式伴生）、`gauge.cornerRadius`（线帽
  round/butt）——全部可选，默认值维持既有形态不变；
- 指针是数据焦点，开启后进度环默认淡化 @60% 让针读数优先（`progressDim`
  可关）。

### 3.12 日历热力图

- **布局**：列 = 周、行 = 星期（`weekStart` 默认周一）；start/end 缺省取数据
  极值并对齐周边界；**格子为矩形、横向铺满绘图区**（宽高独立自适应，圆角 2，
  间隙默认 3）；`granularity: 'week' | 'month'` 聚合为单行周合计 / 月合计
  （求和口径），配合外置按钮可做「每日 / 每周 / 累计」视角切换；
- **色阶**：数值等宽分 4 档 + 空档（0/缺测画空色）——浅色主题用 GitHub 绿阶
  （#ebedf0→#216e39），暗色同构提亮；`calendar.colors` 可整列覆写（5 色）；
- **chrome**：顶部月份标签（11px 次要色，月份变化处标注）、左列星期标签
  （默认只标一/三/五，`showAllWeekdays` 全显）、右下「少 — 多」色阶
  （`showScale: false` 关）；**今日**用主色描边格（`calendar.today` 覆写，
  缺省取当天且在范围内才画）；
- 入场按列序弹出；悬浮格子加深一档 + tooltip（日期 + 数值）；
- 数据字段 `calendarData: [{ date, value }]`，`calendar: { start, end,
  weekStart, colors, cellGap, today, weekdayLabels, showScale,
  showAllWeekdays }`。

## 4. 坐标轴与网格

- **只保留横向网格**；无纵向网格。
- 网格 1px solid，颜色取结构色（极淡）；不支持虚线网格作为默认。
- **轴线不画**：x/y 轴基线与刻度线在 `xAxis.show` / `yAxis.show` 为 false 时整体消失；
  x 轴显示时基线 1px、刻度短横朝下。
- y 刻度样式：`标签 + 短横(6px)` 贴绘图区左缘（「20 –」式），标签右对齐、次要色。
- **轴范围余量**：自动量程时上下余量取「数据极差 10%」与「幅值 5%」的较大者——
  平直数据（内存 580±6 这类）在零基线轴上不顶满绘图区上缘；显式 `min`/`max`
  完全尊重，不追加余量。
- 刻度密度双约束：**显式 `ticks` 是硬上限**——nice 步进产生的多余中间档自动抽稀
  （保首末两端、整数倍步长，round 值不丢）；未显式指定时按**绘图高度自适应**，
  每档 ≥ 24px（矮容器自动降到 2–3 档，监控长条不再挤压）。x 向 `interval` 或每 ~60px 一档。
- **x 类目标签拥挤三步策略**（`interval` 未显式指定时自动生效）：
  1. **抽稀**：相邻标签不重叠（步距 ≥ 标签宽 + 12），放不下按整数步抽稀，
     首末必留；
  2. **截断**：步距允许的最大宽度内省略号截断（单标签仍超步距时）；
  3. **旋转**：`xAxis.rotate` 显式指定时尊重用户（不自动旋转——旋转是排版
     决策，库只保证旋转后的空间预留正确）；
  纵轴（横向条形图分类列）同规则：先截断后抽稀，已按既有省略号逻辑实现。
- **留白回收**：`xAxis.show: false` 时底部 46px 轴位自动收窄为 12px。

## 5. 留白（绘图区与容器边缘）

| 边 | 默认 | 说明 |
| --- | --- | --- |
| top | 18 | 标题 26/副标题 +18、顶部图例带 26 另加 |
| right | 24 | 有右轴 65 |
| bottom | 46 | 底部图例带 26、dataZoom（40+14）另加；隐藏 x 轴 → 12 |
| left | 自适应：y 刻度标签实测宽 + 26，夹在 40–140 | 左图例带另加 80；横向条形图按最宽**分类名**估宽 |

- `options.padding`（数字或四边对象）覆写上表基础值；**标题/图例/dataZoom 的 chrome 空间照常叠加**。
- **列表对齐**：`yAxis.width`（px）显式定 y 轴槽宽，多图传同一值即统一绘图区起点
  （批量小图/监控列表不随各图标签宽窄漂移）；横向条形图同字段为分类列宽；
  `yAxisRight.width` 对称作用于右轴。显式 `padding.left` 优先级最高。
- 长条监控带推荐：`{ top: 6, right: 8, bottom: 6 }` + `height: 64`（left 交刻度标签
  自适应）；sparkline 默认 6px 贴边。
- `padding.left` 不得小于 y 刻度标签最大宽 + 12，否则标签截断。
- **容器不带边框**：是否加框、加多粗由宿主决定，图表只负责内容。嵌入卡片/演示
  容器且宿主底色与 `--ev-bg-color` 不同时，可给容器 `background: transparent`。

## 6. 文字排版

| 元素 | 字号/字重 | 颜色 |
| --- | --- | --- |
| 标题 | 13px / 600，左对齐 | 主文字色 |
| 副标题 | 11px / 400 | 次要色 |
| 图例文字 | 12px / 400 | 次要色 |
| 轴刻度标签 | 11–12px / 400 | 次要色 |
| tooltip 数值 | 13px / 600，tabular-nums | 主文字色 |
| tooltip 标题 | 12px / 400 | 次要色 |

字体栈：`Inter, system-ui, -apple-system, "PingFang SC", sans-serif`；数字场景启用 `tabular-nums`。

## 7. 图例

- 默认样式：12×3 圆角短横条（r1.5）+ 文字，项间距 12，行高 20，默认位置 bottom。
- `icon` 可选 `line` / `circle` / `rect` / `roundRect`；`position` 可选 top / bottom。
- 点选显隐后：图标 alpha 0.4、文字 0.6；悬浮强调（`hoverEmphasis`）默认开启。

## 8. Tooltip

- 容器：浮层面色 + 1px 边框 + 圆角 10 + 阴影 `0 6px 20px rgba(15,23,42,.12)`；padding 9×12。
- 层级：标题行（次要色 12px）→ 项行（色点 6px + 名称 + 数值 600 主色）。
- 位置：优先光标右侧 12px，空间不足左侧，最后垂直翻转；位置变化用 0.25s 缓出滑移。
- **不裁剪**：tooltip 允许浮出图表容器——容器高度装不下时（监控长条等）按视口剩余
  空间选上/下侧溢出显示，杜绝被容器或演示区截断。
- 定制：`tooltip.formatter(params)` 输出任意 HTML（监控带案例的时间戳/大数值/粒度三层即此实现）。

## 9. 叙述注解（annotations）与焦点（emphasis）

注解是数据的旁白：交代峰谷原因、圈出关注区间、给出结论数字。它不是新的数据系列，
也不承担精确读数（那是 tooltip 的事）。

**焦点预算（硬规矩）**

- 单图注解 ≤ 3 处；`emphasis` 焦点系列 ≤ 1 个——铺满旁白的图等于没有重点。
- 注解正文一律 11px 斜体次要色；结论数字可升主文字色 600；系列色/强调色只给
  引线与符号，不给正文。
- 引线一律 1px 虚线（dash 3/3）+ 端点 r2 小圆点；不用实线粗箭头。

**类型与默认形态**

| type | 形态 | 定位字段 |
| --- | --- | --- |
| text | 次要色斜体文字，默认锚在数据点上方 6px 居中 | x（类目/索引）+ y（数值），或 xPx/yPx |
| callout | 旁注文字 + 虚线引线斜拉到数据点 | 同上 + anchor（8 向，默认 top-right） |
| point | 固定高亮点：r3 实心点 + r6 外环（系列色） | 同上 |
| delta | 结论数字：三角符号（路径绘制，非字符）+ 数值/同比，涨跌色跟随 K 线涨跌约定 | 同上 |
| region | 区间强调：primary @6% 填充，标签 11px 置区间顶左内侧 | from / to（类目或索引） |

- 直角系图表（line / area / bar / stacked-bar / mixed / waterfall）先覆盖；
  饼类、雷达后续。
- `offsetX / offsetY` 像素微调；data 定位与像素定位同时给时像素优先。
- 遗留 `annotation: { texts, arrows }` 兼容保留，行为不变。

**焦点（emphasis）**

- `emphasis: { series: '系列名' | 索引, dimOthers: true }`：焦点系列保持原样，
  其余系列与符号统一降到 22% 透明度——与图例悬浮强调同一通道、同一数值。
- 显式 `emphasis` 优先于图例悬浮；移除即恢复。

**图层逃逸口（layers 与 overlay 插槽）**

- `layers: [{ at, draw }]`：canvas 自定义绘制的合法出口。锚点 `back`（数据层
  之下，做背景带/底纹）、`after-series`（系列之后、注解之前，做几何标注底衬）、
  `front`（注解之上、图例之前，默认）。`draw(ctx, renderCtx)` 拿到与渲染器
  同一套 plotArea / theme / options / progress，保证自定义内容跟随主题与布局。
- `#overlay` 作用域插槽：HTML 内容铺满容器，默认 `pointer-events: none`（子元素
  可自行开启），z-index 低于 tooltip——富文本旁白、自定义标记走这里，不与
  canvas 抢交互。
- 使用纪律：能用 annotations 表达的不用 layers；进 layers 的绘制同样遵守
  焦点预算与虚线引线规矩，主题变化时必须读 renderCtx.theme 而不是写死色值。

## 10. 动效

- 首渲/数据变更补间：时长 1200ms、easeOut（五次缓出），数值插值而非闪屏重绘。
- **实时流场景必须关闭**：`animation: { enabled: false }`——每秒推进数据点时补间会让整线反复变形。
- 悬浮反馈（十字准线、圆环、tooltip 显隐）即时响应，不做动画。
- **分幕编排（scenes）**：每幕一个 options 浅合并补丁；`duration` 为该幕过渡时长
  （覆盖全局动画），`hold` 为过渡后停留；`autoplay` 自动推进、`loop` 回卷；
  初始停在第一幕（静态首帧）。手动推进 `nextScene / prevScene / gotoScene`，
  进度受控即挂 `scene-change`。

## 11. dataZoom 与工具箱

- 滑块：默认底部，高 40（含 14 间距），窗口填充 primary @12%，边框准线色。
- 工具箱：右上角导出 PNG / 恢复复位，`filename` 定制下载名。
- 🔜 待精修：滑块手柄圆角与描边、轨道渐变、拖拽态反馈。

## 12. 无障碍（不因风格调整回退）

- 画布 `role="img"` + `aria-label`（`ariaLabel` 或自动生成）。
- 悬浮信息 `aria-live` 播报；空态文案走 i18n。

## 13. 交互规范

三条总纲，与全库设计纪律一脉相承：

1. **悬浮即时**：悬浮反馈（准线、圆环、tooltip 显隐、柱体高亮）零动画；
   动画只属于数据（首渲 / 变更补间）；
2. **反馈走既有通道**：焦点淡化只有一档（22%），图例悬浮与 `emphasis` 共用同一
   通道同一数值；不因新交互发明新视觉语言；
3. **克制**：图表不弹层、不抢焦点、不替使用方做动效。

所有交互常量以 `src/interactions.js` 为单一事实源，本节数值实现必须引用它；
改本节先于改码（与「改视觉先改标准」同一纪律）。

### 13.1 指针与光标

| 区域 | cursor |
| --- | --- |
| 绘图区（直角系 / 极坐标 / 层级） | crosshair |
| 图例 / 工具箱 | pointer |
| 缩放滑块 | grab（拖拽中 grabbing） |
| 其余（标题、留白、tooltip 本体） | default |

### 13.2 hover 行为矩阵

| 图型 | 悬浮反馈 |
| --- | --- |
| line / area / mixed | 竖向准线 + 数据点空心圆环（底色填充 + 系列色描边）+ tooltip |
| scatter | 命中点半径外扩一档（+2）转实心 + 外圈光环 + tooltip |
| bar / stacked-bar / horizontal-bar / waterfall | 柱体高亮（轻度蒙灰 + 顶部高光条）+ tooltip |
| sunburst / treemap | 聚焦子树：本枝原色、其余段与标签淡至 25%（220ms 缓动），被悬浮节点加深一档 |
| sankey / chord / arc / venn / radar | **聚焦缓动族**：强调自身 / 相连、淡化其余的透明度档位随 220ms 缓动进出（进：基准→目标；出场：保留命中索引播完回落再清） |
| 柱族 / 箱线 / K 线 / 漏斗 / 热力 / 日历 / 甘特 | 命中元素强调（同色加深一档 / 高亮带 / 描边）随 220ms 缓动淡入淡出，不位移 |
| 饼类 | 命中扇区抽出 +12px（220ms 缓动进出） |

**全图型悬浮强调一律缓动**（用户定则），仅十字准线、tooltip 显隐与高亮带
（line/area 的竖向反馈）保持即时；图例悬浮 / `emphasis` 的 22% 焦点淡化全局
随 180ms 缓动（`focusAnimProgress` 单一通道）。hover 离开绘图区或按 Esc，
透明度档缓动回落，其余即时清除。

### 13.3 点选与焦点

- 图例点选显隐，隐去残影图标 0.4 / 文字 0.6；`legend.interactive: false` 关闭点选；
- 焦点单一通道：图例悬浮与 `emphasis` 同档 22%，显式 `emphasis` 优先，移除即恢复；
- 数据点单击派发 `click`；`tooltip.trigger: 'click'` 时单击兼作 tooltip 出牌；
- 双击：重置缩放窗口到 0–100%；未启用 dataZoom 时双击无操作（安静原则）；
- **Esc：清除悬浮 / tooltip / 框选拖拽**。

### 13.4 缩放与框选

- 滚轮缩放：以光标为锚点，步进系数 1.15，窗口下限 2%；仅绘图区内生效、
  `mouseWheel: false` 可关；
- 双击复位（同上）；滑块窗口拖拽与手柄见 §11；
- 框选（brush）：按下拖拽出选区，抬起派发 `brush-select`（起止索引），Esc 中止并清除；
- 触屏（🔜 路线图）：单指已等同悬浮 / 点按；双指捏合缩放与长按框选为后续项。

### 13.5 tooltip 内容细则

- 默认 `trigger: 'hover'` 悬浮跟随，`'click'` 点按出牌；
- 多系列默认全显（`showAllSeries: true`），关闭时仅当前系列；
- 行序 = 可见系列的声明序；**空值行不渲染**，全空不弹；
- 位置、形态与翻转规则见 §8。

### 13.6 交互态生命周期

- `setSpec()` 整体替换：图例显隐、缩放窗口、悬浮态全部重置（换图即换态）；

## 15. 配色方案动态切换

站点级预设切换与组件层 API 均已落地（路线图 12–14）；图表层一键固定见 §2.1
「内置色系」（`options.palette`）。

图表数据色板走专用槽位令牌（§2.1），因此「切换配色方案」= 切换 8 个槽位令牌的值，
图表侧无需任何新 API——写入令牌后派发既有 `ev-theme-change` 即触发全量重绘。

- **方案集（presets）**：每套方案 = 8 个槽位 × 浅/暗两组色值（暗色写在 `html.dark` 段，
  随暗色切换自动换挡）。首版预设：品牌蓝板（默认，即 §2.1 表）、青碧板、暖阳板、石墨板。
- **令牌契约**：`--ev-color-series-1..8` 是唯一契约面；槽 1 回读 primary 的行为保留——
  未选方案的宿主保持「单系列跟随品牌主色」的现状。
- **切换时序**：写令牌（同步 setProperty）→ 派发 `ev-theme-change` → 图表监听重绘。
  与暗色/换肤共用同一事件通道，不新增事件。
- **分层落地**：
  1. ✅ #14 charts 内置中性工具 `applySeriesPalette` / `clearSeriesPalette`（src/palette.js）——
     契约的官方实现，宿主调用即可；
  2. ✅ #12 站点级：设计规范页预设按钮（由该工具驱动）；
  3. ✅ #13 组件层：evoke-ui `useThemeConfig.setSeries` / business `setSeriesPalette` 作为宿主封装。
- **业务联动**：`series[].color` 显式指定的颜色不随方案切换（显式优先级最高）。
