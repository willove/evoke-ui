# Evoke Charts 视觉设计标准（v1）

本文件是图表渲染层视觉的**唯一事实标准**：调整任何视觉默认值，先在此文件定稿，再改代码。
对标对象：阿里云/腾讯云控制台监控图、AntV、ECharts 官方示例的克制风格。
状态标记：✅ 已实现 · 🔜 待实现（按优先级排序，落实一项勾一项）。

---

## 1. 设计原则

1. **数据墨水比优先**：网格、轴、边框等结构元素退到视觉背景，墨水留给数据。
2. **克制**：一个图表只允许一个视觉焦点（曲线/柱体本身）；默认无圆点、无阴影、无描边装饰。
3. **一致性**：同层级元素（所有轴标签、所有图例项）字号字色完全一致；色彩饱和度/明度成套。
4. **可读性优先于装饰**：任何装饰性效果不得降低曲线/柱体与背景的对比度。

## 2. 色彩

### 2.1 系列色（数据色）✅

- **数据色板与状态语义色解耦**：优先读取专用令牌 `--ev-color-series-1..8`，
  槽 1 缺省回读 `--ev-color-primary`（品牌主色跟随/换肤不断）；
  未定义的槽位逐槽回落内置成套色板（取材 AntV 经典系，品牌蓝锚定）。
- 顺序即取色顺序：第 1 系列 蓝（主色），后续按槽位顺序。
- **语义色边界**：success / warning / danger / info 是状态语义色，不再默认进入
  数据色板；仅在数据本身承载该状态语义时由使用方通过 `series[].color` 显式指定。

| 2 | `--ev-color-series-2` | `#5AD8A6` | `#5ad8a6` | 156 |
| 3 | `--ev-color-series-3` | `#F6BD16` | `#f6bd16` | 45 |
| 4 | `--ev-color-series-4` | `#6DC8EC` | `#6dc8ec` | 197 |
| 5 | `--ev-color-series-5` | `#E8684A` | `#f08568` | 11 |
| 6 | `--ev-color-series-6` | `#9270CA` | `#a585e8` | 263 |

- 验收：按取色顺序相邻色相差 ≥ 30°（中性槽豁免）；暗色板同色相提亮。

### 2.2 结构色（非数据元素）

| 元素 | 浅色 | 暗色 | 来源令牌 |
| --- | --- | --- | --- |
| 网格线 | `--ev-border-color-light` | `--ev-border-color` | 1px solid |
| 刻度短横 | 同网格线 | 同 | — |
| 轴/图例/刻度文字 | `--ev-text-color-secondary` | 同 | 12px/11px |

| 悬浮高亮带 | primary @ 6%（暗 12%） | 同 | — |

### 2.3 面积填充

- `type: 'area'` 或系列 `area: true`：线性渐变 `颜色 @25% → @2%`（顶→底）。
- 堆叠面积：顶层 `@33%`，避免多系列叠色过深。
- 系列可用 `areaOpacity` 覆写整体透明度。

## 3. 线条与数据点

### 3.1 雷达图

- **填充与面积图同标准**：线性渐变 `颜色 @25% → @3%`（顶→底），多系列叠加不糊；
  `area: false` 关填充只留线框；悬停系列填充微增（@35%→@5%）；
- **线宽 1.5px**（与折线一致），悬停系列 2.5px；
- **顶点符号默认不画**（与折线图同一规矩）：`showSymbol: true` 才画 r3 实心点，
  悬停顶点画「底色圆 + 外环」；
- 网格：5 档多边形环 + 轴线，1px 发丝线；所有维度同 `max` 时在最上轴旁标注
  环刻度数值（10px 次要色），维度各自定 max 时不标（环刻度会有歧义）；
- 维度标签：12px 次要色，`radarLabelOffset` 控制与外环间距（默认 12）。

### 3.2 旭日图

- 环带由内到外按层级均分，中心留白取半径 22%；环与环之间用 2px 背景色描边分隔；
- **段内标签只画放得下的**：深度 0 用 12px 加粗水平排布（弦长 ≥ 文本宽 + 10
  才画）；深度 ≥ 1 的标签**沿半径方向旋转排布**（左半圆翻转 180° 保证可读），
  文字沿环带径向走、永不相撞，颜色按扇区底色自动取反色；
- **最外层叶子的标签外置**到圆盘外侧：水平排布、按角度左右取向，纵向以 13px
  为最小间距扇形防重叠——外圈不再往窄环带里塞字，这是「扩散开」的关键；
- `showValues` 开启时外置标签带数值；悬浮 tooltip 永远可读完整路径，不依赖
  段内标签。

### 3.3 漏斗图

- 段内两行标签：名称 13/600 反白 + 数值 11/400 反白，行距 18px（中心 ±9）；
  梯形中位宽放不下（两侧各留 14px）或层高 < 36px 时自动转外侧引线标签；
- 外侧标签右对齐两行：名称 12/600 主色 + 数值 11 次要色，纵向最小步进 36px
  防重叠，虚线引线随标签位移斜连；
- 标签随进度平滑淡入（进度 72% → 100% 区间 0 → 1），形状展开用 cubic
  ease-out 收尾，不硬蹦；
- 悬浮层片上浮 3px 并加深 13%。

| 项 | 标准值 | 覆写 |
| --- | --- | --- |
| 默认线宽 | 1.5 | `series.lineWidth` |
| 监控带 / 迷你图 | 1.25 | 同 |
| 强调线（单系列主图） | 2 | 同 |
| 线帽/拐角 | round | — |
| 数据点圆点 | **默认不绘制** | `series.showSymbol: true` |
| 悬浮点 | 空心圆环 r4.5 / 环宽 2（showSymbol 关闭时同样生效） | — |
| 平滑曲线 | 默认直线段；`series.smooth: true` 单调三次插值（过点无过冲），chart 级 `options.smooth` 可整图开启 | `series.smooth` |

## 4. 坐标轴与网格

- **只保留横向网格**；无纵向网格。
- 网格 1px solid，颜色取结构色（极淡）；不支持虚线网格作为默认。
- **轴线不画**：x/y 轴基线与刻度线在 `xAxis.show` / `yAxis.show` 为 false 时整体消失；
  x 轴显示时基线 1px、刻度短横朝下。
- y 刻度样式：`标签 + 短横(6px)` 贴绘图区左缘（「20 –」式），标签右对齐、次要色。
- **轴范围余量**：自动量程时上下余量取「数据极差 10%」与「幅值 5%」的较大者——
  平直数据（内存 580±6 这类）在零基线轴上不顶满绘图区上缘；显式 `min`/`max`
  完全尊重，不追加余量。
- 刻度密度双约束：**显式 `ticks` 是硬上限**——nice 步进产生的多余中间档自动抽稀
  （保首末两端、整数倍步长，round 值不丢）；未显式指定时按**绘图高度自适应**，
  每档 ≥ 24px（矮容器自动降到 2–3 档，监控长条不再挤压）。x 向 `interval` 或每 ~60px 一档。
- **留白回收**：`xAxis.show: false` 时底部 46px 轴位自动收窄为 12px。

## 5. 留白（绘图区与容器边缘）

| 边 | 默认 | 说明 |
| --- | --- | --- |
| top | 18 | 标题 26/副标题 +18、顶部图例带 26 另加 |
| right | 24 | 有右轴 65 |
| bottom | 46 | 底部图例带 26、dataZoom（40+14）另加；隐藏 x 轴 → 12 |
| left | 自适应：y 刻度标签实测宽 + 26，夹在 40–140 | 左图例带另加 80；横向条形图按最宽**分类名**估宽 |

- `options.padding`（数字或四边对象）覆写上表基础值；**标题/图例/dataZoom 的 chrome 空间照常叠加**。
- **列表对齐**：`yAxis.width`（px）显式定 y 轴槽宽，多图传同一值即统一绘图区起点
  （批量小图/监控列表不随各图标签宽窄漂移）；横向条形图同字段为分类列宽；
  `yAxisRight.width` 对称作用于右轴。显式 `padding.left` 优先级最高。
- 长条监控带推荐：`{ top: 6, right: 8, bottom: 6 }` + `height: 64`（left 交刻度标签
  自适应）；sparkline 默认 6px 贴边。
- `padding.left` 不得小于 y 刻度标签最大宽 + 12，否则标签截断。
- **容器不带边框**：是否加框、加多粗由宿主决定，图表只负责内容。嵌入卡片/演示
  容器且宿主底色与 `--ev-bg-color` 不同时，可给容器 `background: transparent`。

## 6. 文字排版

| 元素 | 字号/字重 | 颜色 |
| --- | --- | --- |
| 标题 | 13px / 600，左对齐 | 主文字色 |
| 副标题 | 11px / 400 | 次要色 |
| 图例文字 | 12px / 400 | 次要色 |
| 轴刻度标签 | 11–12px / 400 | 次要色 |
| tooltip 数值 | 13px / 600，tabular-nums | 主文字色 |
| tooltip 标题 | 12px / 400 | 次要色 |

字体栈：`Inter, system-ui, -apple-system, "PingFang SC", sans-serif`；数字场景启用 `tabular-nums`。

## 7. 图例

- 默认样式：12×3 圆角短横条（r1.5）+ 文字，项间距 12，行高 20，默认位置 bottom。
- `icon` 可选 `line` / `circle` / `rect` / `roundRect`；`position` 可选 top / bottom。
- 点选显隐后：图标 alpha 0.4、文字 0.6；悬浮强调（`hoverEmphasis`）默认开启。

## 8. Tooltip

- 容器：浮层面色 + 1px 边框 + 圆角 10 + 阴影 `0 6px 20px rgba(15,23,42,.12)`；padding 9×12。
- 层级：标题行（次要色 12px）→ 项行（色点 6px + 名称 + 数值 600 主色）。
- 位置：优先光标右侧 12px，空间不足左侧，最后垂直翻转；位置变化用 0.25s 缓出滑移。
- **不裁剪**：tooltip 允许浮出图表容器——容器高度装不下时（监控长条等）按视口剩余
  空间选上/下侧溢出显示，杜绝被容器或演示区截断。
- 定制：`tooltip.formatter(params)` 输出任意 HTML（监控带案例的时间戳/大数值/粒度三层即此实现）。

## 9. 叙述注解（annotations）与焦点（emphasis）

注解是数据的旁白：交代峰谷原因、圈出关注区间、给出结论数字。它不是新的数据系列，
也不承担精确读数（那是 tooltip 的事）。

**焦点预算（硬规矩）**

- 单图注解 ≤ 3 处；`emphasis` 焦点系列 ≤ 1 个——铺满旁白的图等于没有重点。
- 注解正文一律 11px 斜体次要色；结论数字可升主文字色 600；系列色/强调色只给
  引线与符号，不给正文。
- 引线一律 1px 虚线（dash 3/3）+ 端点 r2 小圆点；不用实线粗箭头。

**类型与默认形态**

| type | 形态 | 定位字段 |
| --- | --- | --- |
| text | 次要色斜体文字，默认锚在数据点上方 6px 居中 | x（类目/索引）+ y（数值），或 xPx/yPx |
| callout | 旁注文字 + 虚线引线斜拉到数据点 | 同上 + anchor（8 向，默认 top-right） |
| point | 固定高亮点：r3 实心点 + r6 外环（系列色） | 同上 |
| delta | 结论数字：三角符号（路径绘制，非字符）+ 数值/同比，涨跌色跟随 K 线涨跌约定 | 同上 |
| region | 区间强调：primary @6% 填充，标签 11px 置区间顶左内侧 | from / to（类目或索引） |

- 直角系图表（line / area / bar / stacked-bar / mixed / waterfall）先覆盖；
  饼类、雷达后续。
- `offsetX / offsetY` 像素微调；data 定位与像素定位同时给时像素优先。
- 遗留 `annotation: { texts, arrows }` 兼容保留，行为不变。

**焦点（emphasis）**

- `emphasis: { series: '系列名' | 索引, dimOthers: true }`：焦点系列保持原样，
  其余系列与符号统一降到 22% 透明度——与图例悬浮强调同一通道、同一数值。
- 显式 `emphasis` 优先于图例悬浮；移除即恢复。

**图层逃逸口（layers 与 overlay 插槽）**

- `layers: [{ at, draw }]`：canvas 自定义绘制的合法出口。锚点 `back`（数据层
  之下，做背景带/底纹）、`after-series`（系列之后、注解之前，做几何标注底衬）、
  `front`（注解之上、图例之前，默认）。`draw(ctx, renderCtx)` 拿到与渲染器
  同一套 plotArea / theme / options / progress，保证自定义内容跟随主题与布局。
- `#overlay` 作用域插槽：HTML 内容铺满容器，默认 `pointer-events: none`（子元素
  可自行开启），z-index 低于 tooltip——富文本旁白、自定义标记走这里，不与
  canvas 抢交互。
- 使用纪律：能用 annotations 表达的不用 layers；进 layers 的绘制同样遵守
  焦点预算与虚线引线规矩，主题变化时必须读 renderCtx.theme 而不是写死色值。

## 10. 动效

- 首渲/数据变更补间：时长 1200ms、easeOut（指数缓出），数值插值而非闪屏重绘。
- **实时流场景必须关闭**：`animation: { enabled: false }`——每秒推进数据点时补间会让整线反复变形。
- 悬浮反馈（十字准线、圆环、tooltip 显隐）即时响应，不做动画。
- **分幕编排（scenes）**：每幕一个 options 浅合并补丁；`duration` 为该幕过渡时长
  （覆盖全局动画），`hold` 为过渡后停留；`autoplay` 自动推进、`loop` 回卷；
  初始停在第一幕（静态首帧）。手动推进 `nextScene / prevScene / gotoScene`，
  进度受控即挂 `scene-change`。

## 11. dataZoom 与工具箱

- 滑块：默认底部，高 40（含 14 间距），窗口填充 primary @12%，边框准线色。
- 工具箱：右上角导出 PNG / 恢复复位，`filename` 定制下载名。
- 🔜 待精修：滑块手柄圆角与描边、轨道渐变、拖拽态反馈。

## 14. 配色方案动态切换（规划稿）

图表数据色板走专用槽位令牌（§2.1），因此「切换配色方案」= 切换 8 个槽位令牌的值，
图表侧无需任何新 API——写入令牌后派发既有 `ev-theme-change` 即触发全量重绘。

- **方案集（presets）**：每套方案 = 8 个槽位 × 浅/暗两组色值（暗色写在 `html.dark` 段，
  随暗色切换自动换挡）。首版预设：品牌蓝板（默认，即 §2.1 表）、青碧板、暖阳板、石墨板。
- **令牌契约**：`--ev-color-series-1..8` 是唯一契约面；槽 1 回读 primary 的行为保留——
  未选方案的宿主保持「单系列跟随品牌主色」的现状。
- **切换时序**：写令牌（同步 setProperty）→ 派发 `ev-theme-change` → 图表监听重绘。
  与暗色/换肤共用同一事件通道，不新增事件。
- **分层落地**：
  1. ✅ #14 charts 内置中性工具 `applySeriesPalette` / `clearSeriesPalette`（src/palette.js）——
     契约的官方实现，宿主调用即可；
