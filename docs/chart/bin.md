# 直方图 bin

把一组原始数值**自动分桶**统计频数：柱高是落在该区间的数据个数。接口耗时分布、订单金额分布等"数据集中在哪里"的问题。

## 何时使用

- 手里是**原始明细数值**（几百上千条），想看分布形态；
- 关心集中区间、离散程度与双峰/离群形态；
- 数据已经有分位统计结果（min/q1/median/q3/max）时改用[箱线图](/chart/boxplot)。

## 示例

沿用 `series.data` 直接传原始数值数组，分箱与频数统计自动完成。

<DemoBlock>
  <ev-chart
    :options="{
      type: 'bin',

      labels: ['耗时'],
      series: [
        { name: '耗时', data: [42, 51, 48, 66, 72, 58, 49, 55, 61, 88, 95, 72, 64, 58, 47, 52, 60, 68, 74, 59, 53, 46, 63, 70, 82, 91, 57, 62] },

## 配置要点

- 传原始数值即可，无需手工分桶；
- 单看分布形态用单系列；多群体对比分布形态时改用[箱线图](/chart/boxplot)更紧凑；
- 柱高即频数，悬浮可读各箱区间与计数。
