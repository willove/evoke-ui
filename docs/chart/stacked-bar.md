# 堆叠柱状图 stacked-bar

把多个系列纵向堆成一根柱：既看**总量**，也看**构成怎么分**。渠道转化构成、成本结构逐月变化等场景的标准答案。

## 何时使用

- 每个类目有多个组成部分，且关注总量；
- 各构成项量级相近（某一项独大时其他项会被压扁，改看[占比章节](/chart/pie)的饼系）；
- 只对比单维度数值、不关心构成，用[柱状图](/chart/bar)。

## 示例

数据模型同柱状图（`labels` + `series`），把 `type` 换成 `stacked-bar`，各系列自动纵向堆叠。

<DemoBlock>
  <ec-chart
    :options="{
      type: 'stacked-bar',
      title: '渠道转化构成',
      labels: ['周一', '周二', '周三', '周四', '周五'],
      series: [
        { name: '自然流量', data: [120, 132, 101, 134, 90] },
        { name: '广告投放', data: [80, 92, 91, 94, 70] },
        { name: '老客召回', data: [45, 52, 61, 48, 66] },
      ],
      legend: { show: true },
    }"
    :height="260"
  />
</DemoBlock>

## 配置要点

- 系列数量建议 2-5 个，再多图例与配色都难以判读；
- 悬浮 tooltip 会展示同柱全部系列，配合图例点选看单系列；
- 关注构成占比的百分比表达时，可先在前端把数据归一化再堆叠。
