# 条形图 horizontal-bar

柱状图的横向变体：柱子横过来，类目轴在纵向。**类目名很长**（渠道名、组织名、接口名）或类目多时，比竖柱易读得多。

## 何时使用

- 类目标签长、竖排会互相挤压；
- 类目多（10-30 个）需要纵向滚动浏览；
- 关注数值排序时，先按数值排序再传入效果最好。

## 示例

数据模型与柱状图完全一致，`type` 换成 `horizontal-bar`，第一个 `label` 出现在最上方。

<DemoBlock>
  <ev-chart
    :options="{
      type: 'horizontal-bar',
      title: '各渠道成交额',
      labels: ['搜索引擎', '直接访问', '外部引流', '社群裂变', '线下扫码'],
      series: [{ name: '成交额（万）', data: [412, 356, 298, 187, 96] }],
    }"
    :height="260"
  />
</DemoBlock>

## 配置要点

- 建议传入前按数值排序，读图成本最低；
- 多系列分组、堆叠语义与竖向柱状图一致（数据多组自动分组）；
- 长列表配合 `dataZoom` 做窗口浏览，见[交互与联动](/chart/interaction)。
