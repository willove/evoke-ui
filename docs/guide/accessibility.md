# 无障碍与对比度

本库以 WCAG 2.1 为无障碍基线：键盘可达（菜单 / 表格 / tabs / select / date-picker 均有完整键盘操作，详见各组件文档）、焦点环全组件覆盖、表单控件带 aria 语义。本页发布**颜色令牌的对比度实测数据**，供选型与合规评估参考。

下表数值由 `design-tokens/` 导出的令牌按 [WCAG 2.1 相对亮度公式](https://www.w3.org/TR/WCAG21/#dfn-contrast-ratio) 计算（明色 = `:root` 令牌；暗色 = `html.dark` 重映射后）。

## 已知缺口与使用建议

对照 WCAG 2.1（AA 常规文字 ≥ 4.5，大字号 ≥ 3.0）如实披露当前缺口：

1. **暗色模式语义色按钮**：暗色下语义色已按惯例提亮（状态文字对比反而更优），但「提亮底色 + 白字」的组合对比不足。使用建议：需要传达关键信息的操作，优先用主色按钮或「浅底 + 深色语义字」的形态；语义色按钮的文字信息配合图标 / 文案语义双重传达，不单靠颜色。
2. **占位文字**：两套模式均低于 3.0。占位符属提示性内容，WCAG 不作强制；必填说明请用 label 或额外提示文字承载，不要只写在 placeholder 里。
3. **白字 / 成功、警告色（明色）**：仅达大字号 AA。14px 常规字重的按钮文字不属大字号——正文场景请优先用「浅底 + 深色语义字」的 Tag / Alert 形态，视觉与合规双达标。

## 令牌事实源

`pnpm tokens:export` 从两库令牌源文件生成 `design-tokens/*.json`（W3C Design Tokens 草案格式），本页数值即基于该导出计算。令牌调整后重跑导出并复算，即可保持本页数据可信。
