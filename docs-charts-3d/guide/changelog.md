# 更新记录

本页同步 npm 包的版本变更，细节见仓库 CHANGELOG。

## 0.1.0

- 首个版本。
- 五种三维图型：`bar3d` 柱状、`line3d` 折线、`scatter3d` 散点、`surface3d` 曲面、`pie3d` 饼/环形；
- 轨道相机：拖拽环绕、滚轮与捏合缩放、Shift 平移、双击复位、方向键、自动旋转；
- 悬浮拾取、图例点选显隐、tooltip、进场动画；
- 主题跟随宿主令牌与暗色，内置七套色系；`applySeriesPalette` / `clearSeriesPalette` 全局换装；
- `exportSVG` 真矢量导出、`toDataURL` 位图导出；`validateOptions3d` 配置校验；
- aria 标注与 aria-live 播报，空 / 载 / 错 / 成四态。
