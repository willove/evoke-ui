# 设计规范

三维图的视觉标准（完整版见仓库内 `packages/charts-3d/DESIGN.md`），本页给使用视角的摘要：
什么时候图会好看，哪些参数动不得。

## 光照

- 默认一盏**跟随相机的肩后主光**：任意视角下顶面最亮、正面居中、侧面最暗，形体永远清晰；
- `lighting.ambient`（默认 0.56）压不住暗面、`intensity`（默认 0.88）控制明暗落差，
  默认值即验收基准，非展示场景不建议动；
- `lighting.direction` 可以把光固定在世界坐标——旋转物体能看到明暗变化，但可能转到暗面，
  仅建议用于产品展示类场景。

## 相机与构图

- 默认机位 yaw -52° / pitch 27°，是三轴都能读清的斜视构图；
- pitch 被限制在 2°–88°：不会钻到地面以下，也不会出现正俯视的「平面图」；
- 柱类目标点略高于地面，饼类对准盘心，构图默认已调平。

## 坐标框

- 墙与轴线的取边**跟随相机**：背墙永远在远侧、轴线刻度贴近边，任意角度下坐标框都在衬托数据；
- 刻度标签在屏幕空间防碰撞：放不下就丢弃，绝不叠字；网格线不随标签抽稀；
- `box.walls` 可选 `back`（默认，单片背墙）/ `side` / `all` / `none`。

## 图型细则（使用视角）

- **bar3d**：柱宽/深默认占带位 62%；缺失值不占位，零值柱保留；
- **line3d**：落地投影线是读数辅助（三维折线没有共同基线），非装饰；
- **scatter3d**：`colorScale` 把 Z 值编码到色带，是表达第四维的正解；
- **surface3d**：矩阵过大自动抽稀（上限 48×48 面片）；线框逐格绘制，保证遮挡正确；
- **pie3d**：悬浮扇区整体上浮（位移强调，不改色）；`innerRadius > 0` 即环形。

## 动效

进场动画：柱/线/散点/曲面按进度生长，饼为角度扫入 + 厚度生长双节奏；默认 600ms。
`animation: { enabled: false }` 直接呈现终态。相机交互不做补间——跟手优先。

## 大数据量

- 曲面按面片上限抽稀；散点/折点的落地线随数据量线性增长，万级点云建议 `scatter: { dropLines: false }`；
- 图元总量建议控制在 1 万以内，超出优先降采样。
