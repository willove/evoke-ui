# 三维图型总览

五种图型共用一个 options 契约与同一台轨道相机：选型只看**数据形态**，切换不改交互习惯。

## 按数据形态选型

| 数据形态 | 图型 | 一句话 |
| --- | --- | --- |
| 类目 × 系列的数值矩阵，要比大小 | [三维柱状图](/chart/bar3d) | 柱林立在网格上，高度即数值 |
| 类目 × 系列要看走势与高度 | [三维折线图](/chart/line3d) | 空间折线悬浮在各自进深层上 |
| 一堆 (x, y, z) 样本点 | [三维散点图](/chart/scatter3d) | 点云看分布，色带可编码第四维 |
| z = f(x, y) 的高度场 | [三维曲面图](/chart/surface3d) | 矩阵进、波面出，连续色带 |
| 占比构成要立体感 | [三维饼图 / 环形图](/chart/pie3d) | 厚片圆盘，悬浮上浮强调 |

## 选型提醒

三维图比二维图**多一个自由度，也多一层遮挡**。选三维之前先过两条：

- 这个图主要给人**看趋势和形体**，还是要**精确读数**？要精确读数（对齐、比较相邻值），
  二维图通常是更好的选择——三维里前后排会互相遮挡；
- 如果用，开启合适的相机角度（别太低）、保留投影参照线（折线图默认开）、
  需要时用 `box.walls` 加背墙增强深度参照。

## 30 秒示例

  <ev-chart3d
    :options="{
      type: 'bar3d',
      title: '季度出货量',
      labels: ['1月', '2月', '3月', '4月', '5月', '6月'],
      series: [
        { name: '华东', data: [420, 380, 500, 460, 540, 610] },

        { name: '西南', data: [180, 220, 260, 240, 300, 280] }

      zAxis: { name: '出货量（件）' }

    :height="340"
  />

拖拽旋转视角，滚轮缩放，悬浮柱体看数值，双击复位。
