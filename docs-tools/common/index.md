# common-tools · 公共工具

`@wil-works/evoke-tools-ui/common` —— 不含办公语义的一层：基准件、通用壳、命令面、面板、反馈与输入。
编辑器、IDE、运维台、办公套件都用这一层；办公形态在 [office-tools](/office/)。

```js
import CommonTools from '@wil-works/evoke-tools-ui/common'
import '@wil-works/evoke-tools-ui/styles'

createApp(App).use(CommonTools)
```
