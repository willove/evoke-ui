# Frontend UI/UX：定调 → 披露 → 自验证

AI 产 UI 的两大病：**模板脸**（渐变 hero + 三等宽卡片，换谁家的 logo 都成立）和**功能堆砌**（工具面板一股脑平铺，用户不知从哪看起）。本规程管住下限；惊艳的上限靠第 1 节的气质锚定。规则全部写成可判定的——形容词不许当验收标准。

## 1. 开工前：先答三个问题（答案写在回复开头）

1. **这个界面像谁？** 用一个短语定气质锚（如"安静的会计软件"、"杂志内页"、"机房监控墙"）。后续所有取舍拿它仲裁：两个方案打架时，选更像它的。
2. **用户 5 秒内要完成的第一件事是什么？** 这是唯一主路径，首屏一切资源为它让路。
3. **哪些功能第一眼可以不看见？** 列"藏的清单"。工具型界面里，藏的清单比露的清单长才是常态（见第 3 节）。

答不出这三个问题不许写代码。

## 2. 反公式化（展示型：落地页/官网/案例页）

- **换标测试**：把品牌元素遮住，页面与任意模板无区别 = 没有设计，只有模板。出货前自查这一条。
- 常见公式件（渐变 hero、三等宽卡片、彩色圆底图标）不是禁用，是**必须改一处结构变量再用**：跨度不等宽、密度有疏密、去圆底、错位排布，任选其一。
- 同构模块连续超过 3 个必须出现变化（尺寸/留白/形态），满屏等距重复即模板脸。
- **一屏一个视觉重心**。数据大屏/概览页：一个 hero 指标，其余指标降级为次要排布。
- 留白是内容：区块间距 ≥ 区块内间距的 2 倍；信息没有主次时，先造主次再排版。
- 图片/插画区域禁拉伸变形，裁切构图优先于缩放。

## 3. 渐进披露（工具型：后台/面板/编辑器/设置页）——核心

- **露出的判据只有一条**：10 个新用户里 8 个在此刻要用 → 露；否则藏。暴露的按钮数量与功能强大无关，与使用频率有关。
- 藏的三档，按代价从低到高选：就地收起（折叠）→ 溢出菜单/"更多" → 设置页/高级模式。
- **每屏强调色主操作 ≤ 2 个**；其余操作一律弱化态（描边钮/文本钮/图标钮）。
- 列表/表格页工具栏只留：搜索 + 主筛选 + 1 个主操作。批量操作、导出、列设置、打印收进溢出菜单。
- 表单超过 8 个可见字段必须分组或分步；"高级选项"默认折叠。
- **空态即首屏**：新用户第一次打开，应看到"一句引导 + 一个主按钮"，不是一个空面板阵或一堆 0 值卡片。
- **可发现性兜底**：藏起来的功能必须有线索——"更多"角标带计数、⌘K 提示、设置项入口。藏 = 不占视野，不是不可达。
- 失败判定：打开面板后用户需要"先读完所有控件才能猜到怎么用" = 功能堆砌，打回重分层。

## 4. 硬规则（可判定，逐条自查）

- 色彩：一主色 + 语义色（成功/警告/危险）；同屏彩色种类 ≤ 3；信息层级靠中性色阶，不靠加彩色。
- hover/激活态：边框只加深一档，禁直接跳强调色；默认动效无位移、无缩放（动效由使用方叠加）。
- 图标：成套同源（如 remix 一套到底），emoji 与图标混排即打回。
- 字号：同屏档位 ≤ 4 级；层级 = 字号 + 字重 + 颜色三通道组合，禁一律加粗。
- 圆角/间距/阴影/描边：各用一档令牌；同类元素同屏必须同值（按钮圆角跟输入框圆角一致之类）。
- 文案：动词开头、说人话、禁翻译腔；按钮文案 ≤ 4 字优先，禁"点击这里"。
- 有设计令牌/组件库的仓库：先查既有组件与令牌，禁绕开组件库手写一次性的样式。本规程管布局与取舍，不替代设计系统。

## 5. 视觉自验证闭环（强制，没截图不许报"完成"）

用会话内浏览器工具（control-browser / tabbit / Playwright 任一）打开实际渲染的页面，截首屏全图 + 关键交互态（hover、展开、空态），然后**逐条写结论**：

1. **三米测试**：眯眼看截图，第一眼落点是否等于第 1 节定的重心？不是就改层级。
2. **换标测试**：遮住品牌元素，这页和模板有区别吗？
3. **删除测试**：可见控件逐个问"新用户此刻需要吗"，答"否"的数量 > 0 就收进下一档披露。
4. **数色**：彩色种类是否 > 3？主色是否散落超过预期？
5. **空态**：清掉数据再看一遍，是引导还是空白/堆面板？

发现问题：**一次只修一类**（布局 → 色彩 → 披露，分开修），修完重截，直到清单全过。"代码看起来是对的"、"我检查过 DOM"不算验证——口头描述一律不算。

## 6. 模板脸 → 改法 对照

| 反例 | 改法 |
| --- | --- |
| 渐变紫蓝 hero + 白卡片三连 | 单色或内容前置的 hero；卡片改不等宽/错位 |
| 图标一律彩色圆底 | 去圆底，或同色系浅底 |
| 工具栏 8 个按钮平铺 | 主操作 1 个 + "更多"溢出菜单 |
| 表格页塞满筛选器 | 1 个搜索框 + 高级筛选折叠 |
| 每张卡片都带操作按钮 | 删到只剩主路径，其余进卡片详情 |
| 概览页 8 个等大指标卡 | 1 个 hero 指标 + 其余降级为紧凑行 |
